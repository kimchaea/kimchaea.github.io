Analysis Principles

분석 과정에서 지킨 기준

데이터 누수 방지 전처리 기준을 학습 데이터에서만 결정하고 평가 데이터에는 동일 기준 적용
불균형 지표 중심 평가 Accuracy만 사용하지 않고 Recall, PR-AUC 등 희소 불량 검출 지표를 함께 확인
운영조건과 모델 분리 단일 threshold를 절대값으로 두지 않고 비용·품질 목표·검사 capacity 관점에서 비교
과도한 해석 방지 익명 센서 중요도를 실제 공정 원인으로 단정하지 않고 추가 점검 후보 수준으로 해석
