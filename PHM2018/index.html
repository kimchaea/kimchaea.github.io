DATA SOURCE · PHM SOCIETY 2018 DATA CHALLENGE · ION MILL ETCH TOOL

PHM 2018

반도체 Ion Mill Etch 설비 데이터를 기반으로 두 가지 분석을 수행했다. 데이터 품질·고장 사전예측과 Multi-task LSTM 기반 RUL 방법론 검증을 각각 진행했다.

Analysis Scope

동일한 데이터셋을 사용했지만 문제 정의와 평가 목적이 달랐다. 첫 번째 프로젝트에서는 데이터 정합성과 고장 예측 가능성을 확인했고, 두 번째 프로젝트에서는 논문 기반 방법론의 재현성과 외부 검증에 초점을 맞췄다.

Projects

PROJECT 01 · DATA QUALITY & FAULT PREDICTION

데이터 품질 · 고장 사전예측

Sensor·TTF·Fault 데이터의 구조와 정합성을 검증하고, 시간 누수를 방지한 시계열 분할과 feature engineering을 적용해 FlowCool Pressure Low 고장의 사전예측 가능성을 평가했다.

  • Sensor 약 506만 행 및 Fault/TTF 구조 점검
  • Timestamp 정렬·중복·라벨 예외 레코드 검증
  • Temporal / Context feature 생성 및 불균형 대응
  • PR-AUC 중심 XGBoost 성능 평가 및 한계 분석

PROJECT 02 · PAPER VALIDATION

Multi-task LSTM · RUL 검증

논문에서 제안된 multi-task LSTM 구조와 추론 규칙을 참고해 RUL 예측 모델을 구현하고, 모델 선택에 사용하지 않은 Outer Validation에서 재현성과 적용 가능성을 검증했다.

  • 2-layer Multi-task LSTM 구현 및 학습 조건 고정
  • Inner validation 기준 epoch budget 설정
  • Outer Validation 기반 독립 성능 검증
  • Paper inference gate 재현 및 예측 실패 원인 분석
